# 单段测试记录模板

复制本模板，为每段测试单独填写。

- 记录ID：〔产品缩写〕-〔C编号〕-〔阶段与轮次，如 P1 / R1〕
- 日期与时间：
- 产品／App版本／语音模式／可见模型：
- 账户档位／音色／基础语速／历史记忆设置：
- 设备／收音方式／网络：
- 输入原话：
- 插话位置或实际停顿：
- 产品原回应：
- 对应证据文件与时间点：
- 客观检查结果：
- 适用评价项及分数：
- 评分理由（指向具体言语或时间点）：
- 不可观测项／执行异常：
- 是否补测及关联ID：
